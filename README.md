# Drum-Lesson
ドラム練習用

## Section C パターン再生ページ

https://tars8000.github.io/Drum-Lesson-inferno/

ブラウザで開くだけで動くドラムパターン再生ページ。外部ライブラリも音源ファイルも使わず、
Web Audio API でキック・スネア・ハイハット・クラッシュを合成しています（オフラインでも動作）。

- 16分 × 2小節のグリッド表示とループ再生、再生位置のハイライト
- テンポ 50〜180 BPM／ハネ（16分シャッフル）0〜60%／音量の調整
- セルをクリックしてパターンを編集
  - ハイハット列: クローズ `x` → オープン `o` → クラッシュ `⊗` → 消す
  - スネア列: 通常 `●` → ゴースト `g` → 消す
- オープンハイハットは次のクローズ音で自動的に止まる
- <kbd>Space</kbd> で再生／停止、「元のパターンに戻す」で初期パターンへ復帰

ローカルで使う場合は `index.html` をブラウザにドラッグするだけです。
