ドラムパターン再現 — Section C

4分ハイハット＋2・4バックビート。2拍目でハイハットをオープン、16分の「ア」でゴーストノート。

⊗ クラッシュ（アクセント） x ハイハット・クローズ o ハイハット・オープン ● スネア g ゴーストノート ● バスドラム

叩き方のポイント

1小節目の頭はクラッシュ＋バスドラ。セクションの入りなのでしっかりアクセントを。
2拍目が肝。足でハイハットを開けながらスネアと同時にヒットし、開けっぱなしのまま16分の「ア」で小さくゴーストノート、3拍目で閉じる。この流れがこのビートのノリを作っています。
バスドラは「1・1と」「3・3と」の8分2連（1小節目の頭だけクラッシュと一緒に4分）。
ゴーストは「スティックを落とすだけ」の音量で。2拍目のスネアと同じ強さにならないように。

セルをクリックすると音を切り替えられます（ハイハット列は x → o → ⊗ → 消す の順で循環）。Space で再生／停止。
